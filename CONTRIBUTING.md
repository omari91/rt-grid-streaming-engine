# Contributing Guidelines

Thank you for your interest in contributing to this power systems project!

## Getting Started
1. Fork the repository and create a new feature branch (`git checkout -b feature/amazing-feature`).
2. Implement your changes adhering to PEP 8 standards.
3. Verify test coverage and linting.
4. Submit a Pull Request targeting `main`.

## Standards & Quality
- Ensure type annotations are added for public functions.
- Write tests for new solver methods and compliance validation logic.
- Follow standard power systems conventions for bus and branch parameters.
